Remote Proxy Router 설정

Edge 트래픽을 원격 HTTPS 프록시로 라우팅합니다. 변경 후 저장을 누르면 라우팅이 켜져 있는 경우 즉시 재적용됩니다.

프록시 서버

프록시 인증 (Basic)

자격증명은 이 브라우저 프로필에만 저장되며 계정 동기화되지 않습니다. 다만 디스크에 평문으로 저장되므로 이 프록시 전용 계정을 사용하고 다른 곳에 재사용하지 마세요.

예외 (프록시를 거치지 않고 직접 연결)

example.com 또는 *.example.com 형식

192.168.49.0/24(폰 핫스팟)와 10.42.0.0/24(tun2proxy 가상 NIC)를 지우면 테더링 경로 자체가 끊깁니다.

누출 방어

헬스체크

ip=, loc= 를 평문으로 돌려주는 엔드포인트여야 출구 IP·국가를 표시할 수 있습니다. 기본값은 Cloudflare 의 trace 입니다.
