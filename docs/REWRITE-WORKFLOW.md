# 기초 과목 문서 재작성 — 작업 절차

`pugs/fundamental/` 의 문서를 자습서로 다시 쓸 때의 절차다.
경로는 모두 **저장소 최상위 기준**이다.

## 0. 목표 한 문장

**중학교 수준의 이해만 가진 사람이 문서를 앞에서부터 읽어 나가면서 막히는 곳 없이
끝까지 이해할 수 있게** 한다. 내용을 줄이라는 뜻이 아니다. 학사 수준까지 간다.
다만 그 길에 계단이 빠진 곳이 없어야 한다.

## 1. 반드시 먼저 읽을 것

| 파일 | 무엇 |
|---|---|
| `docs/SELF-STUDY-SPEC.md` | 재작성 규칙. **전부 지켜야 한다** |
| `CLAUDE.md` | 저장소 규약(pug 문법, 믹스인, SI 단위 정책) |
| `docs/REFERENCE-chapter.pug.txt` | 완성 기준 견본. 밀도·문체·예제 형식을 여기에 맞춘다 |
| `pugs/fundamental/chemistry.pug` 의 `h1 산과 염기` | 또 하나의 좋은 견본. 특히 "로그를 그 자리에서 도입"하는 절 |
| `docs/ledger/<과목>.md` | **독자가 당신 장에 도착했을 때 이미 아는 것**. 이걸 어기면 문서가 깨진다 |

지금 있는 원문은 내용 목록의 출발점으로만 쓰고 **문장은 거의 다 새로 쓴다**.
원문이 버려지는 이유는 틀려서가 아니라 **독자가 이미 안다고 가정한 것이 너무 많아서**다.

## 2. 산출물

```
<작업 폴더>/<과목>/ch<NN>-<slug>.pug     # 장마다 한 파일
figures/<과목>-<블록>.mjs                # 담당자 전용 그림 모듈
d2/<과목>/<이름>.d2                      # 상자·화살표 도식
```

- pug 조각은 `    h1 ...` 로 시작한다(공백 4칸 들여쓰기). 문서에 그대로 붙일 수 있어야 한다.
- 그림 모듈 파일명은 **배정된 이름만** 쓴다. 여럿이 동시에 작업할 때 충돌을 막는 유일한 장치다.
- 그림 이름(`name`)은 과목 전체에서 유일해야 한다. 배정된 접두어를 붙인다.
- `.d2` 는 소스만 만든다. SVG 렌더는 마지막에 한꺼번에 한다.

## 3. 분량 기준

과학 3과목 42개 장의 실적이 기준이다. 장 하나당:

- **250~360줄**
- **예제 11~15개** (각각 `+solution` 하나씩)
- **그림 6~10개** (생성기 SVG + d2 도식 합쳐서)

짧으면 설명이 빠진 것이고, 지나치게 길면 한 장에 두 장을 넣은 것이다.

## 4. pug 문법 — 자주 틀리는 것

```pug
    h1 장 제목
    p 본문. 수식은 식[E = mc^2]식 처럼 쓴다.

    h2 절 제목
    h3 소절 제목            // h1 다음에 h3 로 건너뛰면 안 된다

    +w3img('/figures/physics/kin-atvx.svg', '이 그림에서 읽어낼 것을 적는다')

    +table()
        +ths('머리1', '머리2')
        +tds('칸1', '칸2')

    +example()
        p 문제 문장.
        +solution()
            p 풀이.

    +example('보충')       // 미적분 등이 필요해 건너뛰어도 되는 예제
```

- **굵게는 `<b>...</b>`**. `**굵게**` 는 pug 가 처리하지 않아 그대로 찍힌다.
- 큰따옴표는 `&#34;`, 부등호는 `&lt;` `&gt;` 또는 `\lt` `\gt`.
- **`+ths` / `+tds` 는 인자를 이스케이프한다.** 표 칸에 `<b>` 나 `&#34;` 를 넣으면
  화면에 태그가 그대로 찍힌다. **표 칸에는 평문과 `식[...]식` 만** 넣는다.
  표 칸 안 수식의 역슬래시는 두 번 쓴다: `+tds('규칙', '식[\\log(xy) = \\log x + \\log y]식')`
- **"예제 3" 처럼 번호를 손으로 적지 않는다.** `+example()` 이 자동으로 붙인다.
  다른 예제를 가리켜야 하면 말로 지칭한다("앞의 완충 용액 예제").
- 산문에서 `#[+example('보충')]` 처럼 믹스인을 인라인으로 부르지 마라.
  예제 카운터가 하나 올라가 이후 번호가 전부 밀린다.
- **`+w3img` 의 캡션도 이스케이프된다.** 캡션에 `&#34;` 를 쓰면 화면에 그대로 찍힌다.
  따옴표가 필요하면 `‘ ’` 를 써라.
- 문서 **전체**를 가리키는 링크는 `+asA('/posts/….html', '문서 이름')` 이다.
  `+goto` 는 목적지에 `+pos` 가 있어야 하는데 문서 제목으로는 앵커를 두지 않는다.
- **`식[...]식` 안에서 `\text{}` 를 쓸 때 그 안에 또 `식[...]식` 을 넣지 마라.**
  구분자가 먼저 닫혀 수식이 잘린다. 구분자 개수만 세는 검사도, MathJax 도
  오류를 내지 않으므로 화면을 봐야 드러난다. 한글은 `\text{...}` 안에 그냥 쓴다.
- 탭 문자 금지. 들여쓰기는 공백만.

## 5. 그림 만드는 법

`figures/lib.mjs` 를 읽어라. 사용례는 `figures/chemistry-basic.mjs`,
`figures/physics-kinematics.mjs`, `figures/biology-cell.mjs` 에 있다.

```js
import { svg, frame, px, txt, legend, arc, PALETTE } from './lib.mjs';

const figs = [];
figs.push({ name: 'math-calc-tangent', svg: (() => { /* ... */ return svg({ /* ... */ }); })() });
export default figs;
```

알려진 함정:

- 라벨에 **수식을 쓸 수 없다**(`<img>` 라 MathJax 가 닿지 않는다).
  아래첨자는 `v~0`, `A~{xy}` 표기가 `<tspan>` 으로 내려간다. 그리스 문자는 유니코드로.
- **HTML 엔티티도 쓸 수 없다.** `lib.mjs` 의 `esc` 가 `&` 를 다시 이스케이프한다.
- 그 `~` 치환 때문에 **`45~71%` 같은 물결표가 아래첨자로 먹힌다.** 라벨에서 `~` 를 피하라.
- `txt()` 안에서 `&#34;` 는 이중 이스케이프된다. 따옴표는 `‘ ’` 를 쓴다.
- `px()` 에 `cls: 'ark'`/`'ar1'` 을 넘기면 **선이 사라지고 화살촉만 남는다**
  (그 CSS 클래스가 SVG 안에 없다). `figures/biology-cell.mjs` 의 `arw()` 헬퍼를 본떠라.
- 색은 `PALETTE` 만 쓴다. 다크 모드는 `svg()` 가 알아서 처리한다.
- **라벨끼리 겹치는지 반드시 눈으로 확인하라.** 축 눈금과 곡선 라벨이 가장 자주 부딪친다.
  브라우저로 렌더해 보는 것이 유일하게 믿을 만한 방법이다.

만든 뒤:

```bash
npm run build-figure     # = node source/build/figure.ts
```

`.d2` 는 상자와 화살표 전용이다(좌표 그래프에 쓰지 마라).

```
direction: right
a: 측정값 { shape: rectangle }
b: 유효숫자 판단
a -> b: 자릿수를 센다
```

**한 줄 안에서 키를 구분할 때는 쉼표가 아니라 세미콜론이다.**
`{ label: "갈림길"; style.bold: true }` — 쉼표를 쓰면 컴파일이 실패한다.

## 6. 검사

장 파일을 쓸 때마다 돌린다. 통과할 때까지 고친다.

```bash
node scripts/check-chapter.mjs <장 파일>
```

9가지를 본다: 렌더 성공 / 수식 구분자 짝 / 예제=풀이 / 헤딩 레벨 연속 /
마크다운 잔재 / 수동 예제 번호 / 금지 단위 / 그림 파일 존재 / 탭 없음.

`.d2` 로 만든 도식은 SVG 를 아직 렌더하지 않았다면 8번이 실패한다. 그건 예상된 실패다.

장을 다 합친 뒤에는 문서 단위 검사를 돌린다.

```bash
node scripts/check-doc.mjs pugs/fundamental/<과목>.pug   # 장 사이 연속성, d2 경로 등 11가지
npm run check-links                                      # +goto 앵커 (빌드 뒤에 돌린다)
npm run verify                                           # 실제 브라우저로 404·수식·그림·가로 넘침
```
