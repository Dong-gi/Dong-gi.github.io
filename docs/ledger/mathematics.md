# 기초수학 — 장 사이 인계 목록

`pugs/fundamental/elementary-mathematics.pug` 를 자습서로 다시 쓴다.
**네 사람이 동시에** 쓰므로 서로의 결과를 볼 수 없다. 아래 표가 유일한 계약이다.

## 이 문서가 특별한 이유

이 문서는 **다른 문서들이 "더 알고 싶으면 여기"라고 보내는 목적지**다.
지금 물리·화학·생물에서 링크 8개가 들어온다. 도착해 보면 한 줄짜리 개조식 항목이라
링크의 값이 없는 상태다. 그것을 고치는 것이 이번 작업의 핵심이다.

따라서 **아래 여섯 곳에는 반드시 `+pos()` 앵커를 유지해야 한다.** 지우면 링크가 깨진다.

| 앵커 | 어느 장 | 누가 |
|---|---|---|
| `+pos('지수함수')` | 함수 | B |
| `+pos('로그함수')` | 함수 | B |
| `+pos('삼각함수')` | 함수 | B |
| `+pos('미분')` | 미분 (h1 바로 앞) | C |
| `+pos('미분법')` | 미분 | C |
| `+pos('정적분')` | 적분 | D |

앵커는 해당 헤딩 **바로 앞 줄**에 둔다.

## 담당 A — 3~5장 (명제 / 집합 / 유클리드 기하학)

**들어올 때 독자가 아는 것:** 중학교 수학까지. 그 이상 없다.
사칙연산, 비례와 반비례, 분수와 거듭제곱, 일차함수와 그래프, 간단한 연립방정식,
피타고라스 정리, 원의 둘레와 넓이, 기초 확률.

**도입해야 할 것**

- **3장 명제**: 명제와 진리값, 조건문 식[p \to q]식, 역·이·대우, 필요조건과 충분조건,
  전칭·존재 기호 식[\forall]식 식[\exists]식, 부정, 논리곱·논리합, 드모르간 법칙,
  **증명 방법 네 가지**(직접·대우·귀류법·수학적 귀납법).
  이 장은 뒤의 모든 장에서 "증명"이라는 말을 쓸 근거를 만든다.
- **4장 집합**: 원소와 포함, 부분집합, 합·교·차·여집합, 드모르간, 곱집합,
  **함수의 정의를 집합으로**(정의역·공역·치역, 일대일·위로·일대일대응, 역함수·합성),
  **무한집합과 가산성**을 맛보기로(대각선 논법 한 문단).
  7장의 함수 논의가 여기 정의 위에 선다.
- **5장 유클리드 기하학**: 정의와 공준이 무엇인지, 5번 공준이 왜 특별한지,
  원주각과 중심각, 접선, 방멱(power of a point), 삼각형의 합동·닮음,
  **사인법칙과 코사인법칙**.

**A 가 그 자리에서 도입해야 하는 것 — 중요**

사인법칙·코사인법칙에는 삼각비가 필요한데, **삼각함수는 7장(담당 B)에서 다룬다.**
따라서 5장에서는 **직각삼각형의 삼각비**만 그 자리에서 정의하고 쓴다.
"빗변 분의 높이를 식[\sin]식 이라 부른다" 수준으로 충분하며,
일반각·라디안·그래프·항등식은 **7장에서 다룬다고 명시하고 넘긴다.**
이 경계를 넘으면 B 와 내용이 겹친다.

**B·C·D 에게 넘기는 것:** 명제와 증명, 대우와 귀류법, 수학적 귀납법, 집합 연산,
함수의 집합론적 정의(정의역·치역·역함수·합성), 직각삼각형 삼각비, 닮음.

## 담당 B — 6~7장 (수 체계 / 함수)

**들어올 때 독자가 아는 것:** 중학교 수학 + A 블록(명제·증명·집합·함수의 정의·직각삼각형 삼각비).

**도입해야 할 것**

- **6장 수 체계**: 자연수 → 정수 → 유리수 → 실수 → 복소수로 넓혀 온 이유를
  **"이 수 체계에서는 풀 수 없는 방정식이 있다"**는 한 줄기로 꿴다.
  유리수의 조밀성, **무리수의 존재 증명**(식[\sqrt2]식 귀류법 — A 의 귀류법을 처음 써먹는 자리),
  실수의 완비성을 말로, 절댓값과 부등식, 복소수와 켤레·절댓값,
  **복소평면**과 극형식(여기서 각이 필요하므로 7장 삼각함수를 예고하거나 A 의 삼각비 선에서 처리).
- **7장 함수**: 함수를 그래프로 보는 법, 평행이동과 대칭, 우함수·기함수,
  다항함수와 유리함수(점근선), **지수함수**(지수법칙의 확장 — 정수 → 유리수 → 실수 지수),
  **로그함수**(지수함수의 역함수, 로그 법칙, 밑변환, 식[e]식 와 자연로그),
  **삼각함수**(라디안, 단위원, 일반각, 그래프와 주기, 덧셈정리·배각·반각, 역삼각함수 맛보기).

이 장이 이 문서에서 가장 크다. 360줄을 넘길 것 같으면 절을 압축하되 내용을 빼지 마라.

**앵커 세 개(`지수함수`·`로그함수`·`삼각함수`)를 반드시 남겨라.**

**C·D 에게 넘기는 것:** 실수의 완비성, 절댓값 부등식, 복소수, 그래프 읽기,
지수·로그와 그 법칙, 식[e]식 와 자연로그, 라디안, 삼각함수와 덧셈정리, 역함수.

## 담당 C — 8~10장 (방정식과 부등식 / 극한과 연속 / 미분)

**들어올 때 독자가 아는 것:** A·B 블록 전부. 특히 지수·로그·삼각함수, 복소수,
그래프 읽기, 귀류법과 수학적 귀납법.

**도입해야 할 것**

- **8장 방정식과 부등식**: 지금 원문에 거의 없는 장이니 사실상 새로 쓴다.
  일차·이차방정식과 판별식, 근과 계수의 관계, 고차방정식과 인수정리,
  연립방정식, 부등식의 성질, 이차부등식, 절댓값 부등식, 분수·무리 부등식,
  **산술-기하 평균 부등식**과 코시-슈바르츠(2변수 형태), 방정식의 그래프적 해석.
- **9장 극한과 연속**: 수열의 극한부터 시작해 함수의 극한으로,
  식[\epsilon\text{-}\delta]식 는 **한 문단으로 뜻만** 보이고 계산에는 쓰지 않는다,
  극한의 사칙연산, 샌드위치 정리, 식[\lim_{x\to0}\frac{\sin x}{x}=1]식 (그림으로),
  식[e]식 의 극한 정의, 발산, 연속의 정의와 불연속의 유형, 중간값 정리, 최대·최소 정리.
- **10장 미분**: 평균변화율 → 순간변화율 → **접선의 기울기**, 미분가능성과 연속성,
  미분법(합·곱·몫·합성·역함수), 초등함수의 도함수(다항·지수·로그·삼각),
  음함수 미분, 고계도함수, 평균값 정리와 롤의 정리, 증가·감소와 극값,
  볼록성과 변곡점, 그래프 그리기, 최적화 문제, 로피탈 정리.

**앵커 두 개(`미분`·`미분법`)를 반드시 남겨라.**

**D 에게 넘기는 것:** 극한, 연속, 도함수와 미분법 전체, 평균값 정리,
증가·감소·극값, 초등함수의 도함수 표.

## 담당 D — 11~12장 (적분 / 확률)

**들어올 때 독자가 아는 것:** A·B·C 블록 전부.

**도입해야 할 것**

- **11장 적분**: **넓이를 구하는 문제**에서 출발한다(구분구적법 → 리만 합 → 정적분).
  부정적분과 원시함수, **미적분학의 기본정리**(왜 넓이와 미분이 역관계인가 — 그림으로),
  적분법(치환·부분적분·부분분수), 정적분의 성질, 넓이·부피·곡선의 길이,
  이상적분 맛보기, 수치적분(사다리꼴·심프슨).
  미적분학의 기본정리가 이 문서 전체에서 가장 중요한 정리다. 한 절을 통째로 써라.
- **12장 확률**: 지금 원문은 한 절뿐이니 새로 쓴다.
  경우의 수(합·곱의 법칙), 순열·조합·중복조합, 이항정리,
  표본공간과 사건(A 의 집합 연산을 그대로 쓴다), 확률의 정의(고전적·상대도수·공리적),
  조건부확률과 독립, **베이즈 정리**, 확률변수와 확률분포,
  기댓값과 분산, 이항분포, 정규분포와 표준화, 큰 수의 법칙 맛보기.
  마지막에 원문에 있던 **"사건의 확률이 0이어도 사건이 발생할 수 있다"** 논의를
  연속확률변수 절 안에 자연스럽게 넣어라.

**앵커 하나(`정적분`)를 반드시 남겨라.**

`pugs/fundamental/probability.pug` 라는 별도 문서가 있다(255줄, 확률분포·추정).
**그 문서와 겹치지 않게, 여기는 고등학교~학부 1학년 초입까지만** 다루고
"확률분포와 추정을 더 보려면" 하고 그 문서로 링크한다.

## 이 문서 특유의 주의

**수학 문서의 예제는 "계산 연습"이 되기 쉽다.** SPEC 이 요구하는 것은 그게 아니다.
풀이는 **왜 그 방법을 고르는지**부터 적어야 한다. 쓸 수 있는 예제 유형:

- **계산**: 극한값, 도함수, 정적분, 확률, 방정식의 해
- **판독**: 그래프에서 미분가능하지 않은 점 찾기, 도함수 그래프로 원함수 개형 그리기,
  분포 그래프에서 평균과 표준편차 읽기
- **증명**: 대우로 보이기, 귀류법, 귀납법. 풀이에 "왜 이 방법인가"를 반드시 적는다
- **오류 찾기**: 잘못된 증명에서 틀린 단계 짚기(원문 mcs 문서가 쓰는 방식이며 효과가 좋다)
- **연결**: 앞 장의 도구가 뒤 장에서 어떻게 쓰이는지 확인하는 문제
  (예: 사인법칙을 삼각함수 그래프로 다시 보기)
