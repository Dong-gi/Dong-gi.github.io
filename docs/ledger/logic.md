## 0. 이 문서가 왜 있는가 — mcs 와의 분업

**mcs 문서가 이미 다루는 것을 다시 가르치지 않는다.** mcs 는 명제 결합, 함의, 동치·타당성,
명제 대수, DNF·CNF, SAT, 술어논리, 한정사 순서·부정, 반례 모형, 증명 기법, 대각선 논법을
다룬다. 알고리즘 문서 13장이 P·NP 와 환원을 다룬다.

이 문서의 몫은 그 다음이다.

> mcs 는 **증명이 무엇인지** 가르친다.
> 이 문서는 **증명 체계 자체를 대상으로 삼아 무엇을 말할 수 있는지** 다룬다.

그래서 5·6장(명제논리)과 9·10장(술어논리)은 **요약이고 통과 지점이다.** 거기서 시간을
쓰지 말고 7장(자연연역)부터가 본체라고 생각하라. 13~17장(메타이론과 한계)이 이 문서를
쓰는 이유다.

mcs 에는 `+pos` 앵커가 없다. 따라서 mcs 로 보내는 링크는 **문서 전체를 가리키는
`+asA('/posts/fundamental/mcs.html', 'Mathematics for Computer Science')`** 를 쓴다.
`+goto` 를 쓰면 빈 곳으로 떨어진다.

## 2. 표기 규약 — **반드시 지킬 것**

여러 사람이 쓰므로 표기가 어긋나면 문서가 못 쓰게 된다. 아래가 전부다.

### 2.1 산문 안의 수식 (`식[...]식`)

| 대상 | 표기 | 쓰지 말 것 |
|---|---|---|
| 원자 명제 | 식[P]식, 식[Q]식, 식[R]식 | 소문자 `p`, `q` |
| 부정 | `\lnot` | `\sim`, `\neg`(같으나 통일) |
| 논리곱 | `\land` | `\wedge`, `\cdot`, `&` |
| 논리합 | `\lor` | `\vee` |
| 함의 | `\to` | `\supset`, `\Rightarrow` |
| 동치 | `\leftrightarrow` | `\equiv`, `\Leftrightarrow` |
| 모순 | `\bot` | `\perp`, `F` |
| 진리값 | `\mathrm{T}`, `\mathrm{F}` | `1`/`0`, 참/거짓 기호 |
| 도출 가능 | `\vdash` | `\|-` |
| 의미론적 귀결 | `\vDash` | `\models`, `\|=` |
| 논리식 메타변수 | `\varphi`, `\psi`, `\chi` | `A`, `B`(원자와 헷갈린다) |
| 논리식 집합 | `\Gamma`, `\Delta` | `S`, `X` |
| 술어 | 식[F]식, 식[G]식, 식[H]식 | 식[P]식(원자 명제와 겹친다) |
| 개체상수 | 식[a]식, 식[b]식, 식[c]식 | |
| 변수 | 식[x]식, 식[y]식, 식[z]식 | |
| 한정사 | `\forall x`, `\exists x` | `(x)`, `(\exists x)` |
| 모형 | `\mathcal{M} = \langle D, I \rangle` | |
| 정의역 | 식[D]식 | 식[U]식 |
| 양상 | `\Box`, `\Diamond` | `L`, `M` |

**중요** — 술어에 식[P]식 를 쓰지 않는다. 명제논리의 원자와 겹쳐 독자가 헷갈린다.
9장 이후 술어는 식[F, G, H]식 로 통일한다.

### 2.2 증명 트리 (bussproofs)

`source/build/lib/math.ts` 에 `[tex]/bussproofs` 를 켜 두었다. **display 수식** 안에서 쓴다.

```
\[\begin{prooftree}
\AxiomC{$\varphi \to \psi$}
\AxiomC{$\varphi$}
\BinaryInfC{$\psi$}
\end{prooftree}\]
```

`\AxiomC` `\UnaryInfC` `\BinaryInfC` `\TrinaryInfC` `\RightLabel` 을 쓴다.
가정 방출은 `\RightLabel{\scriptsize $\lnot$I, 1}` 처럼 규칙 이름을 붙여 표시한다.

**단이 넷을 넘는 트리는 그리지 마라.** 화면을 넘치고 읽히지 않는다. 나누거나
피치 스타일(줄 번호 + 근거)로 표를 쓴다. 피치 스타일은 `+table()` 로 만든다.

| 줄 | 논리식 | 근거 |
|---|---|---|
| 1 | 식[P \to Q]식 | 전제 |
| 2 | 식[P]식 | 전제 |
| 3 | 식[Q]식 | 1, 2 식[\to]식E |

### 2.3 SVG 안의 글자 — 유니코드 기호를 쓴다

SVG 는 `<img>` 로 삽입되므로 MathJax 가 닿지 않는다. **LaTeX 을 쓰면 그대로 보인다.**
대신 유니코드를 쓴다. 폰트에 다 있다.

```
¬  ∧  ∨  →  ↔  ⊥  ⊢  ⊨  ∀  ∃  □  ◇  ⊤  ≡  ∈  ⊆  ℳ
```

아래첨자는 mcs·알고리즘과 같은 `v~0` 표기를 쓴다.

## 4. 장별 인계 — 끝낸 사람이 여기 적는다

아래는 각 장이 **다음 장에게 넘기는 것**이다. 형식은 mcs·알고리즘 원장과 같다.

### ch03 논증 — 무엇이 좋은 논증인가 (316줄 · 예제 13 · 그림 6)
- **용어** 논증/전제/결론, 타당·부당, 건전, **반례**, 연역·귀납, 단조성,
  **논증 형식**(argument form)·**대입례**, 전건 긍정·후건 부정(타당) / 후건 긍정·전건 부정(부당)
- **기호** 식[\varphi, \psi, \chi]식(메타변수), 식[\to]식·식[\lnot]식 는 **뜻만** 임시로. 식[\land \lor \leftrightarrow \bot]식 안 씀
- **못 박은 것** 이 문서는 **연역만** 다룬다. "논증"은 연역 논증, "좋다"는 타당하다는 뜻
- **낱말 충돌 처리 완료** — "건전"이 세 곳(이 장의 논증 / mcs 3장의 추론 규칙 / 13장의 증명 체계)에
  쓰인다는 표를 두었다. mcs 가 규칙에 대해 "건전"이라 부른 성질은 이 장의 낱말로 **"타당"** 이다
- 타당한 형식의 대입례는 타당하다. **역은 성립하지 않는다**

### ch04 논증의 형태를 드러내기 (326줄 · 예제 16 · 그림 6)
- **용어** 논리 상항·비논리 상항, **전건·후건**, 충분조건·필요조건, 실질함의(이름과 어긋나는
  세 자리만), **주연결자**(이름과 구실만 — 정의는 5장), 화용적 함축·취소 시험,
  **사전**(원자 ↔ 한국어 대응표), **되읽기**(back-translation)
- **기호** 연결자 다섯을 **속기로만** 씀. 배타적 논리합은 새 기호 없이 조립.
  식[\forall \exists =]식 는 이름만 얹고 9·12장으로 미룸
- **절차** 옮기기 여섯 단계(문장 → 상항 표시 → 원자와 사전 → 뼈대 → 기호와 괄호 → 되읽기)
- 조건문의 진리조건 확정은 **6장으로 미뤘다**(§4 에서 닫힘)

### ch05 명제논리의 문법 (270줄 · 예제 14 · 그림 7)
- **적형식(wff)의 세 조항** — 기저 / 재귀 / **폐포**. 판정할 때 늘 조항 이름을 댄다
- **용어** 형식 언어, 어휘, 문장문자, 항수, 구성열, 주연결자, 부분식, 파스 트리,
  **유일 가독성**(정리 — 증명은 13장), 줄임말·도식, **대상언어·메타언어**, 메타정리, 가산
- **괄호 규약 (문서 전체 계약)** 바깥 괄호 삭제. 우선순위 식[\lnot > \land > \lor > \to > \leftrightarrow]식.
  **식[\land]식·식[\lor]식 는 왼쪽 결합, 식[\to]식·식[\leftrightarrow]식 는 오른쪽 결합**
- **식의 복잡도** 정의 = 파스 트리 높이(문장문자 0, 조항마다 +1)
- **식[\bot]식 은 어휘에 넣지 않았다.** 7장이 어휘에 더한다 = 정의에 조항 하나를 더하는 일
- 13장에 뿌린 씨 — 폐포 조항이 곧 구조적 귀납법의 근거, 확인할 것이 여섯 갈래

### ch06 진리표와 진리함수적 의미론 (349줄 · 예제 15 · 그림 7)
- **기호** 식[v]식(배당), 식[\bar{v}]식(확장 배당), **식[v \vDash \varphi]식**, **식[\Gamma \vDash \varphi]식**
- **정의** 배당 = 문장문자 전체 → 식[\{\mathrm{T},\mathrm{F}\}]식 인 **함수**.
  확장 배당 = 5장 조항 여섯과 **1:1로 짝지은 재귀 정의**
- **용어** 항진명제·모순·우연, 논리적 동치, 만족가능한 집합, 반례 배당, 공허하게 참, 폭발,
  진리함수적 완전성, 적정 집합, 결정 가능
- **의미론적 연역정리** 식[\Gamma \cup \{\varphi\} \vDash \psi]식 ⟺ 식[\Gamma \vDash \varphi \to \psi]식
- **낱말 충돌** "타당"은 이 문서에서 **논증에만** 쓴다. mcs 의 "타당한 식" = 여기서 **항진명제**.
  mcs 의 "일관적" = 여기서 **만족가능한 집합**(일관성은 증명 체계 쪽에 비워 둠)
- **미납 2건, 둘 다 13장 앞** — (가) "식의 값은 그 식에 나오는 문장문자에만 달려 있다" 미증명
  (나) 진리함수적 완전성 개요만. 둘 다 구조적 귀납법이 필요하다
- **7장에 깔아 둔 갈고리 셋** — 반례 탐색의 강제 단계 = 식[\to]식E, 의미론적 연역정리 = 식[\to]식I, 폭발 = 식[\bot]식E

## 5. 흔한 함정 (`docs/REWRITE-WORKFLOW.md` 요약 + 이 문서 고유)

- `+ths` / `+tds` 는 인자를 이스케이프한다. 표 칸에 `<b>` 나 `&#34;` 를 넣으면 태그가 보인다.
  표 칸에는 평문과 `식[...]식` 만 넣고 역슬래시는 두 번 쓴다
- 산문 안에서 `#[+example(...)]` 을 부르면 예제 번호가 올라간다. 링크와 앵커 외에는 인라인 금지
- 부등호는 `\lt \gt \le \ge` 또는 `&lt;` `&gt;`
- `식[...]식` 안의 `\text{}` 속에 다시 `식[...]식` 을 넣으면 **조용히 잘린다.** 절대 금지
- 이 문서 고유 — **`\to` 와 `\vdash` 와 `\vDash` 를 섞지 마라.**
  식[\varphi \to \psi]식 는 논리식이고, 식[\Gamma \vdash \varphi]식 는 증명 체계의 주장이고,
  식[\Gamma \vDash \varphi]식 는 의미론의 주장이다. 세 층을 구분하는 것이 이 문서의 핵심이다

| 3장 증명이란 무엇인가 | 공리적 방법, 추론 규칙, **규칙 하나의 건전성**(194줄) | 증명 체계를 세우지 않는다. 이름 붙은 규칙은 전건 긍정 하나뿐. 식[\vdash]식 를 정의하지 않는다 |
| 5장 논리식 | 진리표, 동치·타당·만족가능·일관, 명제 대수 12규칙, DNF·CNF, SAT 와 P·NP, 술어논리 ∀∃·논의 영역·한정사 순서와 부정·반례 모형 | **형식 언어의 문법(항·원자식·자유/속박변수)이 없다. 구조와 만족 관계 식[\vDash]식 의 형식 정의가 없다. 연역 체계가 없다** |
| 10장 무한집합 | ZFC 공리 아홉 개, 정지 문제(대각선 논법) | **튜링 기계를 정의하지 않는다.** 괴델은 문장 두 개뿐 — 연속체 가설 독립(2786), **제2 불완전성 정리(2787). 제1 정리는 진술조차 없다** |

**이음매로 쓸 자리 두 곳.**

- mcs 1028줄 — 명제 등식 계산의 완전성을 **증명 없이 한 문장으로 주장만** 한다.
  이 문서 14장이 그것을 실제로 증명하면 가장 자연스러운 이음매가 된다
- mcs 1117줄 — "어느 자리에서는 형식화가 멈춘다"고 자백한다. 이 문서의 출발점이 정확히 거기다

**낱말 충돌 주의.** "건전(sound)"이 mcs 3장 194·438~439줄에서 이미
**추론 규칙 하나의 의미론적 성질**로 정의돼 있다. 13장에서 체계 수준의 건전성을
도입할 때 그 뜻을 인용하고 **확장이라고 밝혀야 한다.**

## 7. 자연연역 규칙 목록 — 7장과 11장이 함께 쓴다

forall x: Calgary 방식(Gentzen 자연연역)을 따른다. **아래가 전부이고 더 늘리지 않는다.**

### 명제논리 (7장에서 도입)

| 규칙 | 이름 | 비고 |
|---|---|---|
| 식[\land]식I / 식[\land]식E | 논리곱 도입·제거 | |
| 식[\lor]식I / 식[\lor]식E | 논리합 도입·제거 | 제거는 경우 나누기 |
| 식[\to]식I / 식[\to]식E | 함의 도입·제거 | 도입은 **가정 방출**. 제거는 전건 긍정 |
| 식[\leftrightarrow]식I / 식[\leftrightarrow]식E | 동치 도입·제거 | |
| 식[\lnot]식I / 식[\lnot]식E | 부정 도입·제거 | 도입은 가정 방출 + 식[\bot]식 도출 |
| 식[\bot]식E | 폭발률 | 식[\bot]식 에서 무엇이든 |
| IP | 간접증명(귀류법) | **이 규칙 하나가 고전 논리를 만든다.** 19장에서 이것을 빼면 직관주의가 된다 |
| R | 반복 | |

### 술어논리 (11장에서 추가)

| 규칙 | 변수 조건 |
|---|---|
| 식[\forall]식I | 이름이 열린 가정에 나타나지 않아야 한다 |
| 식[\forall]식E | 없음 |
| 식[\exists]식I | 없음 |
| 식[\exists]식E | 이름이 열린 가정과 결론에 나타나지 않아야 한다 |
| =I / =E | 12장 |

**IP 를 특별 취급하라.** 7장에서 도입할 때 "이 규칙만 성격이 다르다"고 적어 두면
19장에서 직관주의를 설명할 때 되돌아올 자리가 생긴다.

**원장 §7 정정 (ch11 담당자 보고).** 변수 조건 칸이 요약이라 건전성에 필요한 절반이 빠져 있었다.
13장이 규칙별 귀납을 돌리려면 아래가 정확한 진술이다(Open Logic Project 와 같다).

- **식[\exists]식E** — 임시 이름이 열린 가정·결론에 없을 것 **+ 재료 식[\exists x\,\varphi]식 에도 없을 것**
