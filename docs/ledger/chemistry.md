# 화학 — 독자가 이미 아는 것 (9장 시작 시점)

3~8장은 이미 재작성이 끝났다. 파일은 `docs/ledger 참고 — 완성본은 pugs/fundamental/chemistry.pug ch03~ch08*.pug`.
**필요하면 직접 열어 확인하라. 여기 적힌 것은 요약이다.**

## 3장 물질과 측정
물질의 분류(순물질/혼합물/원소/화합물), 물리·화학 변화, 질량보존·일정성분비·배수비례 법칙,
SI 기본량 7개, 접두어, **10의 거듭제곱 표기**, 유효숫자와 그 연산 규칙,
**단위 환산 = 곱해도 되는 1을 곱하기**, 비SI 환산표(문서 전체에서 여기 한 곳뿐),
밀도 식[\rho = m/V]식, 질량백분율.

## 4장 원자 구조
전자·양성자·중성자, 원자번호 식[Z]식, 질량수 식[A]식, 동위원소 표기, 원자량,
**달톤 식[\mathrm{Da}]식**, **몰과 아보가드로 수 식[N_A]식, 몰질량 식[M]식** (여기서 도입했다),
선 스펙트럼, 보어 모형, 에너지 준위의 불연속, 오비탈 s·p·d·f, 양자수,
쌓음 원리·훈트 규칙·파울리 배타 원리, 전자 배치.

## 5장 주기율표
주기·족·블록, 유효핵전하 식[Z_\text{eff}]식, 가리기 효과, 원자·이온 반지름,
이온화 에너지, 전자 친화도, **전기음성도**, 금속성 경향, 족별 특징.

## 6장 화학 결합
옥텟 규칙, 이온 결합과 격자 에너지, 공유 결합, **루이스 구조 그리는 절차**,
형식 전하, 공명, 옥텟 예외, **VSEPR 로 분자 모양**, 결합 극성과 쌍극자 모멘트,
분자 극성, 원자가 결합 이론, **혼성 오비탈** sp/sp²/sp³, σ·π 결합, 분자 오비탈 개요.

## 7장 분자간 힘과 물질의 상태
분산력·쌍극자-쌍극자·**수소 결합**, 힘의 세기 비교,
**켈빈 온도**(여기서 SI 기본단위로 도입), 보일·샤를·아보가드로 법칙,
**이상기체 법칙 식[PV = nRT]식, 식[R = 8.314\,\mathrm{J/(mol\cdot K)}]식**,
분압과 돌턴 법칙, 기체 분자 운동론, **맥스웰-볼츠만 분포**, 확산과 그레이엄 법칙,
압축인자 식[Z]식 와 실제 기체, 반데르발스 식, 액체의 성질(표면장력·점성·증기압),
결정 격자와 단위 세포, **상평형 그림**, 삼중점과 임계점.

## 8장 화학량론
화학식이 뜻하는 것, 몰질량 계산, 조성 백분율, 실험식과 분자식,
화학 반응식 균형 맞추기, 반응식의 몰 비, **한계 반응물**, 이론·실제 수득량과 수득률,
**몰농도 식[c = n/V]식 (단위 식[\mathrm{mol/L}]식)**, 묽힘 식[c_1V_1 = c_2V_2]식,
용액 화학량론과 **적정의 기본 계산**.

## 수학 도구 현황
쓸 수 있다: 사칙연산, 비례·반비례, 일차함수와 그래프, 연립방정식, 지수 표기,
이차방정식(8장 한계 반응물에서 한 번 쓰였다면 그 형태로만).

**아직 도입되지 않았다: 로그, 삼각함수, 미분, 적분.**
로그는 **13장에서 도입한다**. 그러니 9~12장에서는 로그를 쓰면 안 된다.
평형 계산에서 근을 구할 때 이차방정식이 필요하면 그 자리에서 근의 공식을 상기시켜라
(중학교 범위를 살짝 넘으므로 한 문단 정도 설명을 붙인다).

# 당신이 써야 할 것 — 9~12장

원문은 `pugs/fundamental/chemistry.pug` 의
1419~2177 행이다(9장 열화학 / 10장 화학 열역학 / 11장 용액 / 12장 화학 평형).

## 뒷장이 당신에게 의존하는 것 — 반드시 도입하고 넘겨야 한다

이미 완성된 13~17장이 다음을 **당신이 도입했다고 가정하고** 쓰였다.
빠지면 문서가 끊긴다.

| 뒷장 | 필요로 하는 것 | 어느 장에서 |
|---|---|---|
| 14장 전기화학 | 식[\Delta G]식 와 자발성 판정, 식[\Delta G^\circ = -RT\ln K]식 의 근거 | 10장 |
| 14장 전기화학 | 반응지수 식[Q]식, 평형상수 식[K]식, 둘의 비교로 방향 판정 | 12장 |
| 13장 산과 염기 | 평형상수 식[K]식, 르샤틀리에 원리, 평형 계산(ICE 표) | 12장 |
| 13장 산과 염기 | 몰농도(8장에서 이미 나왔다 — 확인만) | 8장 |
| 15장 반응 속도론 | 식[\Delta H]식 (발열/흡열), 식[\Delta G]식 | 9·10장 |

식[\ln]식 을 10장에서 쓰게 되는데 **로그는 13장에서 도입한다.**
처리 방법: 10장에서는 식[\Delta G^\circ = -RT\ln K]식 를 **결과식으로 제시하되
"여기 나오는 식[\ln]식 은 13장에서 다루므로 지금은 이 식을 쓰지 않는다"** 고 밝히고,
9~12장의 모든 계산은 로그 없이 되도록 구성하라. (13장이 로그를 도입한 뒤
14장에서 이 식을 실제로 쓴다.)

## 장별 방향

**9장 열화학** — 계와 주위, 내부에너지, 일과 열, 열용량과 비열, 열량계,
엔탈피 식[\Delta H]식 와 왜 정압에서 편한가, 열화학 반응식, 헤스 법칙,
표준 생성 엔탈피, 결합 엔탈피로 어림하기.
에너지 단위는 **J·kJ 만** 쓴다(cal 금지).

**10장 화학 열역학** — 자발성이란 무엇인가, 엔트로피 식[S]식 를 **확률/경우의 수**로
설명(통계적 정의를 수식 없이), 열역학 제2·제3법칙, 식[\Delta S_\text{계}]식 와
식[\Delta S_\text{주위}]식, 깁스 자유에너지 식[G = H - TS]식,
식[\Delta G = \Delta H - T\Delta S]식 의 네 가지 부호 조합과 온도 의존,
표준 자유에너지 변화, 식[\Delta G]식 와 최대 일.

**11장 용액** — 용해 과정을 에너지로 보기, 용해도와 온도·압력(헨리 법칙),
농도 표현들(몰농도, **몰랄농도**, 몰분율, 질량백분율, ppm) 과 서로 환산,
총괄성 네 가지(증기압 내림·끓는점 오름·어는점 내림·**삼투압**),
반트호프 인자, 콜로이드 간단히.
삼투압은 식[\Pi = icRT]식 로 쓰고 압력은 kPa 로 낸다.

**12장 화학 평형** — 가역 반응과 동적 평형, 평형상수 식[K_c]식·식[K_p]식 와 그 관계,
평형상수의 의미(크기가 말해 주는 것), 반응지수 식[Q]식 와 방향 판정,
**ICE 표로 평형 농도 구하기**(근사법과 그 타당성 검토 포함), 르샤틀리에 원리
(농도·압력·온도), 촉매는 평형을 옮기지 않는다는 것.
