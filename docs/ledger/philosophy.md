## 0. 이 문서가 왜 있는가 — 다른 문서와의 분업

### 0.1 논리학 문서와의 경계 — **가장 중요하다**

`pugs/fundamental/logic.pug` 이 이미 형식 논리 전체를 다룬다.
**아래 왼쪽 칸은 이 문서에서 다시 가르치지 않는다.**

| 논리학 문서가 하는 것 | 이 문서가 하는 것 |
|---|---|
| 타당성·건전성·반례를 **정의**한다 (3장) | 정의를 **쓴다.** 요약 한 표로 되짚고 링크한다 |
| 논증 형식과 대입례, 전건 긍정·후건 부정 (**3장**) | 자연어 논증을 **형식이 보이게 재구성**하는 기술 |
| 형식적 오류 둘(후건 긍정·전건 부정) | **비형식 오류** — 논리학 **3장**이 "다루지 않는다"고 명시하고 넘긴 것 |
| 명제·술어논리의 문법·의미론·자연연역 | 쓰지 않는다. 필요하면 링크 |
| 건전성·완전성·컴팩트성·괴델 | 전혀 다루지 않는다 |
| 양상논리의 형식 체계(K·T·S4·S5, 접근관계) | 가능세계를 **형이상학의 도구로** 쓴다. 공리 체계는 논리학으로 링크 |
| 직관주의·다치·관련성 논리 | 다루지 않는다 |

논리학 문서 **3장**(`논증 — 무엇이 좋은 논증인가`, 116~435행) 의 "비형식 오류는 이름만
적어 둔다" 절이 이렇게 끝난다. **처음 이 원장은 4장이라고 잘못 적었다.** 논리학 문서의
`h1` 은 8행=1장, 95행=2장, 116행=3장, 436행=4장이다.

> 이 문서는 이것들을 다루지 않는다. 중요하지 않아서가 아니라 **형식으로 잡히지 않기 때문**이다.

**그 빚을 이 문서 4장이 갚는다.** 4장 담당자는 논리학 문서 3장의 그 절을 반드시 읽고,
같은 오류 목록(허수아비·인신공격·선결문제 요구·성급한 일반화·거짓 딜레마·권위 호소·
미끄러운 비탈)을 이어받아 **왜 나쁜지, 언제는 나쁘지 않은지**까지 쓴다.

## 3. 표기 규약

### 3.1 수식 (`식[...]식`)

이 문서는 논리학 문서보다 수식이 훨씬 적다. 쓰는 것은 아래가 전부다.
**논리학 문서와 표기를 맞춘다.** 어긋나면 두 문서를 잇달아 읽는 사람이 걸려 넘어진다.

| 대상 | 표기 |
|---|---|
| 논리식 메타변수 | `\varphi`, `\psi`, `\chi` |
| 부정·논리곱·논리합·함의·동치 | `\lnot` `\land` `\lor` `\to` `\leftrightarrow` |
| 한정사 | `\forall x`, `\exists x` |
| 술어 | 식[F]식, 식[G]식, 식[H]식 (식[P]식 를 술어로 쓰지 않는다) |
| 원자 명제 | 식[P]식, 식[Q]식, 식[R]식 |
| 양상 | `\Box`(필연), `\Diamond`(가능) |
| 반사실 조건문 | `\Box\!\to` — 즉 `식[A \Box\!\to C]식`. 읽기: "A 였다면 C 였을 것이다" |
| 확률 | `P(H)`, 조건부는 `P(H \mid E)`. **`P(H|E)` 로 쓰지 마라** — 세로줄이 붙는다 |
| 논증 형식 | `식[\dfrac{\varphi \to \psi, \quad \varphi}{\psi}]식` (논리학 4장과 같은 모양) |

**bussproofs 증명 트리를 쓰지 마라.** 이 문서에는 형식 도출이 없다.

### 3.1-1 논증 재구성의 번호 표기 (4장이 세웠다. 전 장이 따른다)

전제는 `(P1) (P2) …`, 중간 결론은 `(중간 결론 C1)` 또는 본문에서 `(C1)`, 최종 결론은 `(C)`.
글에 없는데 채워 넣은 숨은 전제는 **‘글에 없음’** 이라고 표시한다.
입장을 소개할 때 "이 입장은 (P2)를 부인한다" 처럼 **어느 전제를 끊는지**로 적으면
문서 전체가 같은 어휘를 쓰게 된다. 6·7·8·12장이 이미 그렇게 쓰고 있다.

### 3.2 SVG 안의 글자 — 유니코드

SVG 는 `<img>` 로 삽입되므로 MathJax 가 닿지 않는다. LaTeX 을 쓰면 그대로 보인다.

```
¬  ∧  ∨  →  ↔  ∀  ∃  □  ◇  ⊨  ∈  ⊆  ≠  ≈  ×  ✓  ✗  ⇒
```

아래첨자는 `w~1` 표기. **라벨 안에서 `~` 를 다른 뜻으로 쓰지 마라**(아래첨자로 먹힌다).
따옴표는 `‘ ’` 를 쓴다(`&#34;` 는 이중 이스케이프된다).

### 3.3 인용

원문을 옮길 때는 **짧게, 큰따옴표(`&#34;`)와 함께, 출처를 붙여서** 쓴다.
번역이 필요하면 번역이라고 밝힌다. §7 의 라이선스 표를 먼저 보라.

## 4. 이 문서의 핵심 문제 — 합의되지 않은 내용

수학·과학 문서에는 없던 문제다. 규격 `SELF-STUDY-SPEC.md` §3-3 이 이것 때문에 생겼다.
**반드시 §3-3 을 읽고 시작하라.** 여기서는 이 과목에 맞게 구체화한다.

### 4.1 세 등급을 구분해 적는다

| 등급 | 어떻게 쓰는가 |

| **정설** | 그냥 서술한다. 표시하지 않는다 |

어긋나면 §9 에 적고 고쳐라. (이 분류 자체가 필자의 판단이며, 다툼의 여지가 있다.)

### 4.2 하지 말 것 셋

1. **숫자로 비율을 적지 마라.** "철학자의 56%가 …" 는 설문(PhilPapers 조사 등) 하나에
   기대는 문장이고, 표본·문항·연도를 문서 안에서 재현할 수 없다. 무게는 말로 적어라.
   꼭 쓰겠다면 조사 이름·연도·표본 크기를 같은 문장에 넣고 **설문 결과일 뿐임**을 밝혀라.
2. **반대 견해를 약하게 요약해 놓고 무너뜨리지 마라.** 그 입장을 지지하는 사람이 읽고
   "내 입장이 맞게 적혔다" 할 문장이어야 한다.
3. **미결을 결론인 척하지 마라.** "따라서 X이다" 와 "나는 X 쪽이 낫다고 본다" 는 다르다.
   후자를 쓸 자리에서 전자를 쓰면 문서가 거짓말을 한다.

## 8. 흔한 함정

`docs/REWRITE-WORKFLOW.md` §4·§5 를 먼저 읽어라. 이 문서 고유의 함정은 이것들이다.

1. **논리학 문서와 겹치기.** §0.1 표의 왼쪽 칸을 쓰고 있으면 멈춰라.
2. **입장 목록만 늘어놓기.** "A 는 이렇게 말하고 B 는 저렇게 말한다"로 끝나는 절은
   독자에게 아무것도 남기지 않는다. **각 입장이 무엇을 설명하려고 그렇게 말하는지,
   그 대가로 무엇을 포기하는지**를 적어야 절이 성립한다.
3. **사고실험을 줄거리만 소개하기.** 사고실험은 **직관을 끌어내려고** 만든 장치다.
   무엇을 묻는지, 왜 그 답이 나오는지, 그 직관이 무엇을 지지하는지까지 써야 한다.
4. **연도·저작·인용을 지어내기.** 확실하지 않으면 연도를 빼고 쓴다. 규격 §3-4.
   추측이면 추측이라고 적어라.
5. **`함의`를 implicature 뜻으로 쓰기.** §2.3.
6. **`P(H|E)`** — `\mid` 를 써라. §3.1.
7. **d2 한 줄 안의 키 구분자는 세미콜론.** 쉼표는 컴파일 실패.
8. **`+ths`/`+tds` 는 인자를 이스케이프한다.** 표 칸에 `<b>` 를 넣지 마라.
   역슬래시는 두 번 쓴다: `+tds('필연', '식[\\Box \\varphi]식')`
9. **그림 라벨에 `~`** — 아래첨자로 먹힌다.

검사는 장을 쓸 때마다 돌린다.

```bash
node scripts/check-chapter.mjs /root/work/philosophy/chNN-*.pug
```

### 11.5 다음에 이 작업을 할 사람에게

세 평가자가 **같은 진단**을 내놓았다. 결함의 대부분이 내용이 아니라 **이음매**에서
나왔다는 것이다. 장을 나눠 쓰면 각 장은 튼튼한데 장 사이가 어긋난다 —
정의되기 전에 쓰인 용어, 틀린 장 번호, 갈린 표기, 실제와 다른 머리말 표.

`scripts/check-chapter.mjs` 는 장 하나만 본다. **합친 뒤에 기계로 검사할 것을 늘리면
이번에 나온 결함의 절반 이상이 자동으로 잡힌다.**

1. **용어 첫 등장 검사** — 굵게 표시된 용어가 정의보다 먼저 쓰였는지
2. **장 참조 검사** — 본문의 &#34;N장&#34; 이 실제로 그 내용을 다루는지
3. **인물 괄호 중복 검사** — 원어 병기가 두 번 이상 나오는지
4. **`li` 중첩 검사** — 형제 항목이 앞 항목 안으로 들어갔는지
5. **머리말 표 대조** — `권장 순서` 표의 선행 장이 실제 참조와 맞는지
